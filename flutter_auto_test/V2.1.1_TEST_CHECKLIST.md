# AutoTest V2.1.1 功能测试清单

## 安装说明
```bash
adb install /workspace/flutter_auto_test/build/app/outputs/flutter-apk/app-debug.apk
```

## 权限配置（必须）
1. **无障碍服务**：设置 → 无障碍 → 已下载的服务 → AutoTest → 开启
2. **悬浮窗权限**：设置 → 应用管理 → AutoTest → 权限管理 → 悬浮窗 → 允许
3. **存储权限**：同上 → 存储权限 → 允许

---

## 功能测试清单

### 1. 首页
- [ ] 显示 7 个功能入口（录制用例、回放执行、测试报告、多账号、导入用例、选择APP、小程序）
- [ ] 授权状态显示正确（已授权/未授权）
- [ ] 点击"设置"按钮跳转到设置页面

### 2. 录制用例
- [ ] 点击"开始录制"按钮，提示"正在录制"
- [ ] 切换到目标 APP 进行操作（点击、输入、滑动）
- [ ] 点击"停止录制"，提示"保存成功"
- [ ] 已保存用例列表显示录制的用例
- [ ] 点击悬浮窗"录制"按钮，开始录制
- [ ] 点击悬浮窗"停止"按钮，停止录制
- [ ] 点击"删除"按钮，确认后删除用例

### 3. 回放执行
- [ ] 显示已保存的用例列表
- [ ] 点击"执行"按钮，执行用例
- [ ] 进度条正确显示执行进度
- [ ] 执行完成后显示结果
- [ ] 点击"导出"按钮，选择保存位置，导出成功
- [ ] 导出后点击"打开"按钮，正确打开文件
- [ ] 点击"删除"按钮，确认后删除用例

### 4. 测试报告
- [ ] 显示已生成的报告列表
- [ ] 点击"删除"按钮，确认后删除报告
- [ ] 点击"清空所有报告"，确认后清空
- [ ] 点击"导出"按钮，选择保存位置，导出成功
- [ ] 导出后点击"打开"按钮，正确打开文件

### 5. 导入用例
- [ ] 点击"下载模板"，选择保存位置，下载成功
- [ ] 下载后点击"打开"按钮，正确打开模板文件
- [ ] 点击"选择文件"，选择 JSON/CSV/XLSX 文件，导入成功
- [ ] 导入后用例出现在"回放执行"列表

### 6. 选择APP（新增）
- [ ] 显示已安装的 APP 列表
- [ ] 搜索框可以过滤 APP
- [ ] 点击 APP，弹出引导对话框
- [ ] 选择"分析APP结构"，跳转到分析页面
- [ ] 选择"选择已有用例"，跳转到回放页面（过滤该 APP 的用例）
- [ ] 选择"录制新用例"，跳转到录制页面
- [ ] 点击"分析"按钮，跳转到结构分析页面

### 7. 小程序（新增）
- [ ] 显示小程序页面
- [ ] 输入小程序路径，点击"启动小程序"
- [ ] 点击常用小程序列表中的"启动"按钮
- [ ] 正确启动微信小程序

### 8. 悬浮窗控制面板（新增）
- [ ] 在录制页面点击"显示悬浮窗"
- [ ] 悬浮窗出现在屏幕上方
- [ ] 点击"录制"按钮，开始录制
- [ ] 点击"回放"按钮，开始回放
- [ ] 点击"停止"按钮，停止操作
- [ ] 点击"关闭"按钮，悬浮窗消失
